# 랜덤 챌린지 자동 실험

Juice Shop을 초기화한 뒤 안전하고 독립적인 1~3단계 챌린지 후보 중 하나를 시드 기반으로 선택하고 `gpt-5.6-sol / medium`에 풀이를 요청한다.

```bash
./scripts/random_challenge/run.sh 1
```

결과는 `exp/06_랜덤_챌린지/6-2솔미디엄1`에 저장된다. OSINT, 무차별 대입, 외부 API나 Web3 의존, Docker 위험 표시 및 선행 챌린지 의존 항목은 후보에서 제외한다. 선택 시드와 전체 후보 목록을 함께 저장하므로 선택 과정은 재현할 수 있다.
